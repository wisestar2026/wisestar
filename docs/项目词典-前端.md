# 项目词典 · 前端（wisestar-client）

本文档是 `wisestar-client/` 前端源码的文件级词典，覆盖 95 个 `.js` / `.jsx` 文件（路由、页面、组件、API 模块、状态与工具、关键约定）。

- 技术栈：React 19 + Ant Design 6 + react-router-dom + zustand + Vite 5
- 目录结构：`src/App.jsx`（路由根）、`src/main.jsx`（入口）、`src/api/`、`src/components/`、`src/pages/`、`src/stores/`、`src/utils/`
- 阅读方式：先看「一、路由总表」定位页面文件，再按「二、页面词典」查职责；组件、API、状态与工具分别见第三、四、五节；开发约定见第六节
- 说明：所有陈述均基于源码。凡源码未明确的信息标注「未确认」；`未挂载路由` 表示文件存在但 `App.jsx` 未引用

## 一、路由总表

路由表来源：`src/App.jsx`。管理端路由统一由 `<AuthGuard adminOnly>`（仅 `userType=SysUser`）+ `<MainLayout />` 包裹，学员端由 `<AuthGuard>` + `<StudentLayout />` 包裹；每条子路由可再套一层 `<AuthGuard required=[...]>` 做权限点校验（`required` 为「任一命中即放行」）。

## 二、页面词典

### src/pages/login/LoginPage.jsx
- **归属**：登录 / 认证
- **职责**：管理端登录；收集用户名密码，调用 `useUserStore.login()`（内部 RSA 加密），成功后 `navigate('/')`；提供学员端登录入口链接
- **导出**：`default`（`LoginPage`）
- **依赖**：`react-router-dom`、`antd`、`../../stores/useUserStore`
- **被引用**：`App.jsx`（`/login` 公开路由）

### src/pages/login/RegisterPage.jsx
- **归属**：登录 / 认证
- **职责**：注册页（昵称/用户名/密码），调用 `api/user.js` 的 `register()`；**未挂载路由**（`/register` 已改为重定向 `/login`）
- **导出**：`default`（`RegisterPage`）
- **依赖**：`../../api/user`
- **被引用**：无（保留文件）

### src/pages/student/StudentLoginPage.jsx
- **归属**：学员端 / 认证
- **职责**：学员账号（学号）+ 密码登录，成功后进入 `/student`；`userType` 非 `Student` 时提示改用管理端入口
- **导出**：`default`（`StudentLoginPage`）
- **依赖**：`../../stores/useUserStore`、`./studentLogin.css`
- **被引用**：`App.jsx`（`/student-login` 公开路由）

### src/pages/student/StudentLayout.jsx

- **依赖**：`../../stores/useStudentStore`、`../../stores/useUserStore`、`../../api/student`、`../../api/studentStudy`、`../../components/common/IconTile`

## 四、API 模块词典

统一约定：`src/api/request.js` 创建 axios 实例，`baseURL=/api`（Vite 代理到后端 1991），`withCredentials` 携带 `sk-token` Cookie，响应拦截器解包 `{code, data, message}`。下表路径为模块内 `request.*` 调用的相对路径（实际请求前缀 `/api`）。文件上传类接口走原生 axios + `multipart/form-data`，不经拦截器。

### src/api/request.js
- **归属**：HTTP 出口

## 六、前端关键约定

1. **HTTP 出口唯一**：所有 JSON 接口经 `src/api/request.js`（`baseURL=/api`，`withCredentials`，30s 超时）。响应体统一 `{code, data, message}`；拦截器成功后返回整包，业务代码取 `.data`。分页结构统一 `{ total, list }`。
2. **文件上传例外**：图片/Excel 上传走原生 axios + `multipart/form-data`，不经拦截器，需手动检查 `code`（`upload.js`、`repo.importTemplate`、`system.importDictItems`、`knowledge` 的批量导入）；Excel 下载通过隐藏 `<a>` 标签直接访问 `/api/...` 触发浏览器原生下载。
3. **认证流程**：`getSystemInfo()` 取 RSA 公钥 → `jsencrypt` 加密密码 → `POST /api/public/login` → 后端 `Set-Cookie sk-token`；刷新时 `App` 挂载调用 `fetchCurrentUser`（GET /api/currentUser）恢复登录态。
4. **权限三层**：`MainLayout` 菜单按 `required` 过滤（任一点命中显示）；`AuthGuard required` 做路由校验；`usePermission().can/canAny` 做按钮级控制。权限点来源 `user.authorityList`。
5. **路由守卫**：`AuthGuard` 的 `loading` 期间返回 `null`（防未登录闪屏）；`adminOnly` 限制管理端仅 `SysUser`；学员端路由限制 `Student`。
6. **两种界面**：管理端（admin/teacher/principal/consultant/academic，`MainLayout` 裸 div + `Title level={4}` 风格）与学员端（海洋童趣风格，样式在 `src/pages/student/student.css`）。
7. **学员端数据回退**：`useStudentStore` 在真实接口失败时回退 mock 内容并置 `loadFailed`；按订单权限过滤可见学科/年级/版本（`getVisibleSubjects`/`getVisibleGrades`/`getVisibleVersions`）。
8. **纯净学习模式**：`useStudentStore.pureMode` 控制，开启后学员端隐藏积分/学习币/头衔等激励模块（DOM 移除）。
9. **练习绑定规则**：练习仅支持绑定到小节（章节只作分组）；题目唯一录入入口是「题目管理」，其余页面只做选择/绑定。
10. **判分一致性**：前端 `utils/practiceHelpers.js` 与后端判分语义对齐（多选集合相等、填空逐空部分给分、全角/空白归一化）。
11. **题型口径**：题库仅五种题型（`utils/questionTypes.js`）；问卷题型另有一套（`utils/surveyHelpers.js`，不含判断题）。
12. **英语独立词库**：英语数据走 `t_english_word`/`t_english_grammar`，不经通用知识链路；部分英语页面直接以 `API_BASE` 常量调 `/api/english/*`。
13. **问卷/答卷接口保留但无引用**：`api/answer.js`、`api/project.js`、`api/survey.js` 对应的旧问卷系统页面已从前端移除，接口留作历史兼容。
