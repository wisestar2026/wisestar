# 项目词典 · 前端（wisestar-client）

本文档是 `wisestar-client/` 前端源码的文件级词典，覆盖 125 个 `.js` / `.jsx` 文件（路由、页面、组件、API 模块、状态与工具、关键约定）。

- 技术栈：React 19 + Ant Design 6 + react-router-dom + zustand + Vite 5
- 目录结构：`src/App.jsx`（路由根）、`src/main.jsx`（入口）、`src/api/`、`src/components/`、`src/pages/`、`src/stores/`、`src/utils/`
- 阅读方式：先看「一、路由总表」定位页面文件，再按「二、页面词典」查职责；组件、API、状态与工具分别见第三、四、五节；开发约定见第六节
- 说明：所有陈述均基于源码。凡源码未明确的信息标注「未确认」；`未挂载路由` 表示文件存在但 `App.jsx` 未引用

## 一、路由总表

路由表来源：`src/App.jsx`。管理端路由统一由 `<AuthGuard adminOnly>`（仅 `userType=SysUser`）+ `<MainLayout />` 包裹，学员端由 `<AuthGuard>` + `<StudentLayout />` 包裹；每条子路由可再套一层 `<AuthGuard required=[...]>` 做权限点校验（`required` 为「任一命中即放行」）。

## 二、页面词典

### src/pages/login/LoginPage.jsx
- **归属**：登录 / 认证
- **职责**：管理端登录；收集用户名密码，调用 `useUserStore.login()`（内部 RSA 加密），成功后 `navigate('/')`；提供学员端登录入口链接
- **导出**：`default`（`LoginPage`）
- **依赖**：`react-router-dom`、`antd`、`../../stores/useUserStore`
- **被引用**：`App.jsx`（`/login` 公开路由）

### src/pages/login/RegisterPage.jsx
- **归属**：登录 / 认证
- **职责**：注册页（昵称/用户名/密码），调用 `api/user.js` 的 `register()`；**未挂载路由**（`/register` 已改为重定向 `/login`）
- **导出**：`default`（`RegisterPage`）
- **依赖**：`../../api/user`
- **被引用**：无（保留文件）

### src/pages/student/StudentLoginPage.jsx
- **归属**：学员端 / 认证
- **职责**：学员账号（学号）+ 密码登录，成功后进入 `/student`；`userType` 非 `Student` 时提示改用管理端入口
- **导出**：`default`（`StudentLoginPage`）
- **依赖**：`../../stores/useUserStore`、`./studentLogin.css`
- **被引用**：`App.jsx`（`/student-login` 公开路由）

### src/pages/student/StudentLayout.jsx
- **归属**：学员端 / 布局
- **职责**：学员端公共布局（顶部通栏 + 学科 Tab / 版本 / 年级 / 册别 / 纯净模式 + `<Outlet />`）；统一学习心跳上报；纯净模式下移除激励模块 DOM；仅学员端首页 `/student` 可切换学科/年级/册别，其余页面这四项下拉置灰只读（仅展示当前值，不可操作）；册别下拉选项来自 `useStudentStore.getVisibleTerms(activeSubject)`，仅列出当前学科有效授权的册别；教材版本不在锁定范围内、始终可切换；切换学科后整页刷新，按新学科重建数据与入口；底部胶囊导航 `.sll-tabbar` 尺寸（图标 `--it-size`、字号、内边距、`bottom`、内容区 `.sll-main` 底部留白）全部改用 `clamp()`/`vw` 随视口自适应放大（基准 1920 视口下图标约 46px），大屏更醒目、小屏不溢出；垂直内边距收紧使胶囊整体高度不超过按钮内容（图标+文字）高度的 1.5 倍（各视口实测比值 1.36~1.45）；非首页（`pathname !== '/student'`）渲染左下角大号悬浮「返回上一级」按钮 `.sll-back-float`（点击按信息架构回**结构父级**而非浏览器 history：`/student/english/*`→`/student/english`、`/student/knowledge[/:id]`→`/student/study`、其余二级页→`/student`；窄屏 ≤760px 抬高避让底部导航），降低误点顶部「退出登录」风险；背景波浪装饰改为 `will-change: transform` + `translateX` 合成层平移（替代逐帧重绘的 `background-position` 动画）以提升流畅度；阅读理解路由进入专注模式：`.sll-focus-read` 隐藏底部导航、左下悬浮返回与右下 AI 按钮，`.sll-main` 上下留白压缩至 `8px/10px`，把高度让给短文/题目两栏容器
- **导出**：`default`（`StudentLayout`）
- **依赖**：`../../stores/useStudentStore`、`../../stores/useUserStore`、`../../api/student`、`../../api/studentStudy`、`../../components/common/IconTile`
- **被引用**：`App.jsx`（`/student` 父级布局）

### src/pages/student/StudentHomePage.jsx
- **归属**：学员端 / 首页
- **职责**：学员首页（海洋智学 · 航海驾驶舱）：左栏商城/错题本/今日任务/**学习检测**四个入口 + 船图展示（不可点击，仅「开始学习」按钮进入学习）+ 右缘图标悬浮卡（今日学习数据总览/积分获取引导/每日签到/今日学习总结，默认只露图标、点击展开）+ 今日任务抽屉；挂载 `OnlineChestFloat`；`.slh-panel` 不设最小高度并随视口弹性收缩，100% 缩放下宽屏（≥1024px）无纵向/横向滚动，矮视口（≤780px/≤660px 高）逐级压缩左栏入口；宽屏下 `.slh-root` 限宽 `calc((100vh - 209px) * 2)`（约 2:1，宽度≈2×容器高）并居中，使容器比例与宽度接近平板端；「开始学习」按钮上移（`bottom:56px`）避免被底部导航遮挡；「学习检测」为紫色强调入口（`.slh-side-detect`，accent `#8a5cf6`），点击打开弹窗：按当前学科拉取 `getDetectUnits`，以复选框多选单元（支持全选/清空），再选择「知识点检测」（跳 `/student/detect?unitIds=`，知识点检测页按其预选多个单元）或「学习诊断」（跳 `/student/diagnose`）；「学习档案」已从左栏移入右缘悬浮卡 `FloatCard title="学习档案" icon="📘" tone="green"`（点击跳 `/student/archive`）
- **导出**：`default`（`StudentHomePage`）
- **依赖**：`../../stores/useStudentStore`、`../../api/student`、`../../api/studentTask`、`../../api/studentStudy`、`../../components/common/IconTile`、`./OnlineChestFloat`
- **被引用**：`App.jsx`（`/student` index）

- **导出**：`default`（`OnlineChestFloat`）

## 四、API 模块词典

统一约定：`src/api/request.js` 创建 axios 实例，`baseURL=/api`（Vite 代理到后端 1991），`withCredentials` 携带 `sk-token` Cookie，响应拦截器解包 `{code, data, message}`。下表路径为模块内 `request.*` 调用的相对路径（实际请求前缀 `/api`）。文件上传类接口走原生 axios + `multipart/form-data`，不经拦截器。

### src/api/request.js
- **归属**：HTTP 出口
- **职责**：统一 axios 实例与响应拦截器；成功返回整个 `{code,data,message}`，`code!=200` 时 `message.error` 并 reject；HTTP 401 跳 `/login`，403/404/5xx/网络错误分别提示
- **导出**：`default`（axios 实例）
- **被引用**：`src/api/` 下所有业务模块

### src/api/archive.js
- **归属**：学员学习档案 API（管理端 + 学员端）

| 导出函数 | 对应后端接口（方法 + 路径） | 用途 |
| --- | --- | --- |
| `getArchiveDetail` | GET /student/archive/detail | 档案详情（传 studentId + 可选 semester） |
| `getArchiveOverview` | GET /student/archive/overview | 档案概览（是否建档 / 记录数 / 报告状态） |

## 五、状态与工具

### src/stores/useUserStore.js
- **归属**：全局状态（管理端用户）
- **职责**：唯一全局登录态源；状态 `user` / `isLoggedIn` / `loading`（初始 `true`，避免刷新误跳登录）；方法 `fetchCurrentUser`（GET /currentUser 恢复登录态）、`login`（RSA 加密登录 + 二次拉用户）、`logout`（登出清状态）
- **导出**：`default`（zustand store）
- **依赖**：`../api/user`

### src/stores/useStudentStore.js
- **归属**：全局状态（学员端）
- **职责**：学员端学科/年级/版本/册别选择、权限、学习内容与进度、纯净模式；含 mock 回退与派生 helper（按订单权限过滤可见学科/年级/版本/册别，`getVisibleTerms(subjectKey)` 返回该学科有效授权册别，空则回退上下册）；`setSubject`/`fetchPermissions`/`normalizeSelection` 按授权册别对齐 `term`，防越权残留
- **导出**：`GRADES`、`TITLES`、`LEVELS`、`masteryLevel`、`SUBJECTS`、`GOODS`、`TODAY`、`DAILY_TASKS`、`REWARDS`、`getQuestions`、`PROFILE`、`default`（store）
- **依赖**：`../api/student`

### src/stores/useKnowledgeStore.js
- **归属**：全局状态（知识管理 mock）
- **职责**：知识管理板块的纯前端 mock 状态（学科→章节→小节→知识点）；提供章节/小节/知识点增删改与内容/练习/题型设置方法
- **导出**：`QUESTION_TYPES`、`DIFFICULTY_OPTIONS`、`default`（store）

### src/utils/usePermission.js
- **归属**：工具 / 权限 hook
- **职责**：按钮级权限；基于 `user.authorityList` 提供 `authorities`、`can(p)`、`canAny(ps)`
- **导出**：`usePermission`
- **依赖**：`../stores/useUserStore`

### src/utils/questionTypes.js
- **归属**：工具 / 题型常量
- **职责**：题库维度的五种题型（判断/单选/单项填空/多选/多项填空）及题型中文标签（兼容历史问卷题型）、填空类题型集合
- **导出**：`EXAM_TYPES`、`EXAM_TYPE_VALUES`、`BLANK_TYPE_VALUES`、`TYPE_LABELS`、`typeLabel`

### src/utils/surveyHelpers.js
- **归属**：工具 / 问卷结构
- **职责**：问卷 JSON 树结构工具；题型常量（不含判断题）、空白问卷骨架、问题/选项节点创建、深拷贝、系统题目转问卷问题节点（含知识点快照）
- **导出**：`QUESTION_TYPES`、`TYPES_WITH_OPTIONS`、`createEmptySurvey`、`createQuestion`、`createOption`、`cloneSurvey`、`templateToQuestion`

### src/utils/cycleDecimal.js
- **归属**：工具 / 判分

### src/utils/richText.js
- **归属**：工具 / 富文本
- **职责**：结构化文本解析纯函数（无 JSX 依赖），供 `RichContent` 使用。`normalizeStructuredText` 统一换行并裁剪；原文无换行但含连续小问标记（（1）/(1)/[1]/1. 1、/①②③）时按编号严格 1..n（2~12 项）自动补换行，保护小数、日期、公式区间不误断；**含空位标记 `__①__` 的题干（单项/多项填空）不做自动小问断行**（圈号是空位编号而非小问分隔符，否则会把一行口算题拆成「① __；…」多行错位）。`parseRichBlocks` 将文本解析为块数组（`heading`【标题】/`item` 编号或项目符号行带 `level` 缩进 /`para` 普通段 /`blank` 空行），并导出圈号常量

## 六、前端关键约定

1. **HTTP 出口唯一**：所有 JSON 接口经 `src/api/request.js`（`baseURL=/api`，`withCredentials`，30s 超时）。响应体统一 `{code, data, message}`；拦截器成功后返回整包，业务代码取 `.data`。分页结构统一 `{ total, list }`。
2. **文件上传例外**：图片/Excel 上传走原生 axios + `multipart/form-data`，不经拦截器，需手动检查 `code`（`upload.js`、`repo.importTemplate`、`system.importDictItems`、`knowledge` 的批量导入）；Excel 下载通过隐藏 `<a>` 标签直接访问 `/api/...` 触发浏览器原生下载。
3. **认证流程**：`getSystemInfo()` 取 RSA 公钥 → `jsencrypt` 加密密码 → `POST /api/public/login` → 后端 `Set-Cookie sk-token`；刷新时 `App` 挂载调用 `fetchCurrentUser`（GET /api/currentUser）恢复登录态。
4. **权限三层**：`MainLayout` 菜单按 `required` 过滤（任一点命中显示）；`AuthGuard required` 做路由校验；`usePermission().can/canAny` 做按钮级控制。权限点来源 `user.authorityList`。
5. **路由守卫**：`AuthGuard` 的 `loading` 期间返回 `null`（防未登录闪屏）；`adminOnly` 限制管理端仅 `SysUser`；学员端路由限制 `Student`。
6. **两种界面**：管理端（admin/teacher/principal/consultant/academic，`MainLayout` 裸 div + `Title level={4}` 风格）与学员端（海洋童趣风格，样式在 `src/pages/student/student.css`）。
7. **学员端数据回退**：`useStudentStore` 在真实接口失败时回退 mock 内容；章节加载失败专用标记 `chaptersFailed`（成功清零，研习页据此提示），其余内容失败不置标记；按订单权限过滤可见学科/年级/版本（`getVisibleSubjects`/`getVisibleGrades`/`getVisibleVersions`）。
8. **纯净学习模式**：`useStudentStore.pureMode` 控制，开启后学员端隐藏积分/学习币/头衔等激励模块（DOM 移除）。
9. **练习绑定规则**：练习仅支持绑定到小节（章节只作分组）；题目唯一录入入口是「题目管理」，其余页面只做选择/绑定。
10. **判分一致性**：前端 `utils/practiceHelpers.js` 与后端判分语义对齐（多选集合相等、填空逐空部分给分、全角/空白归一化）。
11. **题型口径**：题库仅五种题型（`utils/questionTypes.js`）；问卷题型另有一套（`utils/surveyHelpers.js`，不含判断题）。
12. **英语独立词库**：英语数据走 `t_english_word`/`t_english_grammar`，不经通用知识链路；部分英语页面直接以 `API_BASE` 常量调 `/api/english/*`。
13. **问卷/答卷前端已移除**：`api/answer.js`、`api/project.js`、`api/survey.js` 及旧问卷系统页面已于 2026-09-26 删除；`utils/surveyHelpers.js` 因题目编辑组件仍用其 schema 工具函数而保留。
14. **结构化文本展示**：知识点讲解要点、题目题干、选项、解析等自由文本统一经 `components/common/RichContent` 渲染，支持多行/行首小问编号/项目符号的缩进分行；录入端（知识点要点、题干）使用 `Input.TextArea` 保留换行。解析逻辑集中在 `utils/richText.js`，仅在无换行时对严格连续小问编号自动断行，避免误伤小数/公式；含空位标记 `__①__` 的题干不做自动断行，避免把一行口算题拆错位。
15. **后台表格统一规范**：由 `src/index.css` 全局收敛（非逐页配置）——`.ant-table-content`/`.ant-table-body` 横向滚动、所有 `th/td` 不换行、末列（惯例为「操作」列）`position:sticky; right:0` 吸附。新增后台表格无需再手写 `scroll`/`fixed`；注意不要给 `.ant-table` 容器设 `min-width:max-content`（曾导致部分页面宽度暴涨到约 1e6 px）。
