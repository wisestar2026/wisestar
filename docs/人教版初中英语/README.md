# 人教版初中英语 单词 / 句子 / 语法（核对稿）

本目录是从**国家中小学智慧教育平台**电子教材（义务教育教科书·人教版）整理出的初中英语 7-9 年级内容核对稿；词/句/语法已在第 254~256 节入库，本目录作为原文与词表核对来源。

- 版本说明：平台上这几册均为「依据《义务教育英语课程标准（2022年版）》修订」。目录里出现的 2024/2025/2026 年度只是同一课标的逐年重印，内容一致；这里取最新重印（七上、八上取 2026 年度，七下取 2025 年度，八下/九上仅有单一年度）。
- 单词来源：教材附录 `Vocabulary in Each Unit`（OCR 后按页码切分单元），已剔除重名、断行、页码串行等 OCR 噪声；专有名词单列，不计入重点词汇。
- 句子/语法来源：教材目录页的单元主题问题、Section A 情境问题、Section B 语篇描述、Grammar 语法点；七年级上册过渡单元另取目录中的 Key Sentences 功能句。
- 已知缺口：平台上**人教版没有九年级下册**（九下只有科普/沪教/沪外教/译林等版本）。九下是否沿用旧版或另行补充，待确认。

## 与旧数据的差异（重要）

1. 当前系统里 7-9 年级存的是**外研版**；本稿是人教版，入库时需要把初中三年整体切到人教版（小学 3-6 仍外研版）。
2. 核对中发现旧稿若干单元名有误，以下为教材正文/附录确认的正确单元名：
   - 八年级下册：Unit 2 Stay Healthy（旧误作 Stay Safe）、Unit 3 Growing Up（旧误作 Be Positive）、Unit 4 The Wonders of Nature（旧误作 Explore Nature）。
   - 九年级上册：Unit 1 The Changing World（旧误作 Changes）、Unit 2 Inspiring People（旧误作 Great People）、Unit 3 Smart Learning（旧误作 Learn to Learn）、Unit 4 Our Memory（旧误作 Memory）。
3. 各册词汇量与人教版附录一致，但个别 OCR 粘连（如人名/多词专名）已尽量拆分，仍需人工抽查专有名词表。
