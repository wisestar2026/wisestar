# 学员学习评价与薄弱点规则说明

版本：第一版
更新日期：2026 年 9 月 10 日
适用范围：学员端

## 一、总则

为了帮助学员看清自己学得怎么样、哪里薄弱、下一步该练什么，系统对每个知识点给出一个**掌握度**，并据此标记**薄弱知识点**。评价体系要做到三点：

1. 依据真实练习表现，不靠人工设定。
2. 计算简单可解释，学员看得懂。
3. 与错题本口径一致，不给学员两套互相矛盾的说法。

评价结果用于引导学员练习和攻克薄弱点。学海积分是荣誉评价，只用于头衔、证书和学情展示，不参与商品兑换。

## 二、评价依据

掌握度与薄弱点只看学员自己的真实数据：

- 每一次练习和试炼的逐题作答记录。
- 每一道题的作答对错。
- 每一道错题是否已经订正。

错题本是这些数据的另一种展示，掌握度与薄弱点与错题本来自同一份数据，因此不会出现「错题本说错了、掌握度说会了」的情况。

## 三、知识点掌握度怎么计算

掌握度是一个 0 到 100 的整数，数值越大表示掌握得越好。计算方式如下：

1. 找出学员最近 5 次练到的、与这个知识点有关的练习。
2. 算出每一次练习中该知识点的正确率。
3. 越近的练习越重要：最近一次权重最高，往前依次降低。
4. 按权重把各次正确率加起来，得到掌握度。

举例：某知识点最近三次练习的正确率分别是 100%、60%、20%。最近一次最重要，所以掌握度会更接近 100%，而不是简单平均。这样设计是为了反映学员**当前**的真实水平。

如果练习次数不足 5 次，就按已有的几次计算。

## 四、五级评级

掌握度对应五个等级，学员一眼就能看出状态：

| 等级 | 掌握度 |
|---|---|
| 精通 | 85 及以上 |
| 熟练 | 70 到 84 |
| 夯实 | 55 到 69 |
| 待巩固 | 40 到 54 |
| 待攻克 | 40 以下 |

## 五、薄弱点怎么判定

满足以下任一条件，系统就把该知识点标记为薄弱：

1. 掌握度低于 55，也就是处于「待巩固」或「待攻克」。
2. 该知识点还有没有订正的错题。

薄弱知识点会出现在学员的薄弱清单里，用醒目的标记提示，并给出攻克后能获得的积分与学习币。系统只对学员已开通学科内的知识点做判定。

## 六、如何攻克薄弱点

1. 学员针对薄弱知识点做专项练习或复测。
2. 当次正确率达到 80% 及以上，并且掌握度达到 70 及以上，系统就认为该知识点已经攻克。
3. 攻克后，该知识点从薄弱清单中移除，并记录攻克次数。
4. 同一知识点的攻克奖励只发放一次：学习币 +25、学海积分 +12。
5. 如果之后又练得不理想，掌握度掉回 55 以下，或者又出现了没订正的错题，该知识点会重新回到薄弱清单。

## 七、错题与掌握度的联动

错题不是单独一套逻辑，而是掌握度的一部分：

1. 学员把某道错题重做正确后，这道题就从错题本中移除。
2. 如果这个知识点已经没有未订正的错题，而且掌握度不低于 55，它就不再是薄弱点。
3. 如果重做还是错，错题保留，评价不变。
4. 错题订正完成后，系统按规则发放学习币 +8、学海积分 +4。

## 八、学情总览的含义

学情总览向学员展示四个数：

| 项目 | 含义 |
|---|---|
| 累计知识点 | 学员已经练过并记录掌握度的知识点数量 |
| 达标章节 | 学习进度达到要求的章节数量 |
| 薄弱知识点 | 当前还在薄弱清单里的知识点数量 |
| 总积分 | 学员累计的学海积分 |

这四个数必须和其他页面一致：薄弱数与薄弱清单条数一致，总积分与积分板块一致。

## 九、内容调整时的稳定性

章节、小节、知识点以后会变化，但评价体系要保持稳定：

1. 教学内容新增、修改、删除、移动，都不改变学员已有的掌握度与薄弱状态记录。
2. 历史评价以当时的作答记录为准，不因内容调整而追溯改变。
3. 掌握度算法、评级门槛、薄弱与攻克判定规则不随内容变化。
4. 如果某个知识点被移除，只在清单中停用该条目，历史评价记录保留。

## 十、展示与引导

1. 研习页在章节和知识点上直接显示掌握度、评级和薄弱标记。
2. 知识点详情页显示掌握度、薄弱状态以及是否已经预习。
3. 学员第一次练到的知识点，掌握度从 0 开始，等级显示为「待攻克」，不使用任何演示数据。
4. 薄弱清单和主页提示共同引导学员去做练习、订正错题、攻克薄弱点，形成「练习—评价—补弱—再练习」的闭环。
