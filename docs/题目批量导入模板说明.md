# 题目批量导入模板说明（可直接交给 AI 平台汇编）

本文件用于指导 AI 平台按统一格式汇编题目，产物为**一个 `.xlsx` 文件**，可在「题目管理 → 导入」直接上传。

## 一、交付要求

- 文件格式：`.xlsx`（或 `.xls`）。
- **只解析第一个 sheet**，名称建议为「题目列表」。
- 第一行必须是表头，**共 22 列，顺序与名称一字不差**：

| 序号 | 列名 | 必填 | 说明 |
| --- | --- | --- | --- |
| 1 | 学科 | 是 | 系统内已存在的学科名称（如 `数学`），不会自动新建学科 |
| 2 | 题型 | 是 | 仅 5 种：`判断` / `单选` / `单项填空` / `多选` / `多项填空` |
| 3 | 章节 | 是 | 该学科下已存在的章节名称 |
| 4 | 小节 | 否 | 该章节下已存在的小节名称；填写时知识点须属于该小节 |
| 5 | 知识点 | 是 | 整格按一个知识点名匹配；未命中时按顿号拆分多个分别校验 |
| 6 | 题目 | 是 | 题干文本，支持富内容（见第三节） |
| 7 | 选项A | 单选/多选必填 | 选项内容；其余题型留空 |
| 8 | 选项B | 单选/多选必填 | 同上 |
| 9 | 选项C | 否 | 同上 |
| 10 | 选项D | 否 | 同上 |
| 11 | 选项E | 否 | 同上 |
| 12 | 选项F | 否 | 同上 |
| 13 | 选项G | 否 | 同上 |
| 14 | 选项H | 否 | 同上 |
| 15 | 难易程度 | 否 | `简单` / `中等` / `困难` |
| 16 | 正确答案1 | 是 | 见第二节 |
| 17 | 正确答案2 | 否 | 多选的第 2 个字母；多项填空的第 2 空 |
| 18 | 正确答案3 | 否 | 同上 |
| 19 | 正确答案4 | 否 | 同上 |
| 20 | 正确答案5 | 否 | 同上 |
| 21 | 解析 | 否 | 支持富内容（见第三节） |
| 22 | 标签 | 否 | 多个用逗号或顿号分隔 |

## 二、题型与答案填写规则

| 题型 | 选项列 | 正确答案列 | 示例 |
| --- | --- | --- | --- |
| 判断 | 留空 | 正确答案1 填 `正确` 或 `错误` | `正确` |
| 单选 | 选项A~D 等 | 正确答案1 填选项字母 | `B` |
| 多选 | 选项A~D 等 | 正确答案1~5 依次填字母 | `A`、`C`（分两列） |
| 单项填空 | 留空 | 正确答案1 填答案文本 | `3.14` |
| 多项填空 | 留空 | 正确答案1~5 按空位顺序各填一空 | `5x`、`3y`（分两列） |

> 若题目内图片/公式作为答案的一部分，答案列同样支持富内容语法。

## 三、富内容语法（题干 / 选项 / 解析通用）

学员端会自动渲染以下写法，**直接写在单元格文本里**：

| 内容 | 写法 | 示例 |
| --- | --- | --- |
| 图片 | `![图片说明](图片URL)` | `![数轴图](https://example.com/a.png)` |
| 行内公式 | `$...$` | `$x^2$`、`$\frac{a}{b}$`、`$|x|=3$` |
| 独立公式 | `$$...$$` | `$$\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$` |
| 化学式 | `$\ce{...}$` | `$\ce{2H2 + O2 -> 2H2O}$` |
| 加粗 | `**重点内容**` | `**注意单位**` |
| 换行 | 单元格内按 `Alt+Enter` | — |

约束：

- 图片 URL 必须是**公网可访问**的 `http`/`https` 地址；本地图片请先上传到可访问的图床，或单独提供。
- 公式内容为 LaTeX，**不要**在外面再套 `\( \)`；行内用单 `$`，独立用双 `$$`。
- 单元格内不要出现裸露的 `$` 金额写法与公式混用（如 `$5`），避免被误判为公式。

## 四、校验规则（导入失败会整体中止并提示行号）

1. 学科必须已存在，章节必须属于该学科。
2. 小节若填写，必须属于该章节；知识点必须属于所填小节/章节。
3. 单选/多选必须提供选项，且正确答案字母能在选项中找到。
4. 多项填空的答案列数应与空位一致（按正确答案1~5从左到右顺序）。
5. 题型只允许上表 5 种。

## 五、示例行

| 学科 | 题型 | 章节 | 小节 | 知识点 | 题目 | 选项A | 选项B | 选项C | 选项D | 难易 | 答案1 | 答案2 | 解析 | 标签 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 数学 | 判断 | 有理数 | 数轴 | 相反数 | 0 的相反数是 0。 | | | | | 简单 | 正确 | | 0 的相反数是其本身。 | 基础 |
| 数学 | 单选 | 有理数 | 数轴 | 绝对值 | 如图，点 A 表示的数是 $x$，且 $|x|=3$，则 $x$ 的值是？![数轴图](https://example.com/number-axis.png) | 3 | -3 | $\pm 3$ | 以上都不对 | 中等 | C | | 由 $|x|=3$ 得 $x=3$ 或 $x=-3$，故 $x=\pm 3$。 | 易错 |
| 数学 | 多项填空 | 整式加减 | 去括号 | 合并同类项 | 化简后两式的结果分别是？ | | | | | 简单 | 5x | 3y | 合并同类项系数相加减。 | 计算 |

## 六、给 AI 平台的指令模板（可整段复制）

```text
请把下面这批题目整理成一个 .xlsx 文件，用于导入「学海智习」题库。

要求：
1. 第一个 sheet 表头严格为以下 22 列，顺序与名称一字不差：
   学科,题型,章节,小节,知识点,题目,选项A,选项B,选项C,选项D,选项E,选项F,选项G,选项H,难易程度,正确答案1,正确答案2,正确答案3,正确答案4,正确答案5,解析,标签
2. 题型只用：判断、单选、单项填空、多选、多项填空。
3. 答案规则：判断填「正确/错误」；单选填「A」；多选把字母依次填到“正确答案1..5”；单选填空填答案文本；多项填空把各空答案依次填到“正确答案1..5”。
4. 题干、选项、解析中如需图片，写 Markdown：![说明](公网http(s)图片URL)；
   如需公式，行内写 $...$，独立写 $$...$$，内容用 LaTeX；加粗写 **...**。
5. 学科/章节/小节/知识点必须使用系统中已有的名称，不要自造。
6. 每道题占一行，不要合并单元格，不要在单元格内写换行以外的排版。

待整理的题目如下：
（在此粘贴题目内容）
```

## 七、导入位置

「题目管理」页 → 「导入」→ 选择上面生成的 `.xlsx` → 确认导入。
