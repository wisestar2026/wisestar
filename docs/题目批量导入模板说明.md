# 题目批量导入模板说明（可直接交给 AI 平台汇编）

本文件用于指导 AI 平台按统一格式汇编题目，产物为**一个 `.xlsx` 文件**，可在「题目管理 → 导入」直接上传。

## 一、交付要求

- 文件格式：`.xlsx`（或 `.xls`）。
- **只解析第一个 sheet**，名称建议为「题目列表」。
- 第一行必须是表头，**共 30 列，顺序与名称一字不差**：

| 序号 | 列名 | 必填 | 说明 |
| --- | --- | --- | --- |
| 1 | 学科 | 是 | 系统内已存在的学科名称（如 `数学`），不会自动新建学科 |
| 2 | 题型 | 是 | 仅 5 种：`判断` / `单选` / `单项填空` / `多选` / `多项填空` |
| 3 | 章节 | 是 | 该学科下已存在的章节名称 |
| 4 | 小节 | 否 | 该章节下已存在的小节名称；填写时知识点须属于该小节 |
| 5 | 知识点 | 是 | 整格按一个知识点名匹配；未命中时按顿号拆分多个分别校验 |
| 6 | 题目 | 是 | 题干文本，支持富内容（见第三节） |
| 7 | 选项A | 单选/多选必填 | 选项内容；其余题型留空 |
| 8 | 选项B | 单选/多选必填 | 同上 |
| 9 | 选项C | 否 | 同上 |
| 10 | 选项D | 否 | 同上 |
| 11 | 选项E | 否 | 同上 |
| 12 | 选项F | 否 | 同上 |
| 13 | 选项G | 否 | 同上 |
| 14 | 选项H | 否 | 同上 |
| 15 | 难易程度 | 否 | `简单` / `中等` / `困难` |
| 16 | 正确答案1 | 是 | 见第二节 |
| 17 | 正确答案2 | 否 | 多选的第 2 个字母；多项填空的第 2 空 |
| 18 | 正确答案3 | 否 | 同上 |
| 19 | 正确答案4 | 否 | 同上 |
| 20 | 正确答案5 | 否 | 同上 |
| 21 | 正确答案6 | 否 | 同上 |
| 22 | 正确答案7 | 否 | 同上 |
| 23 | 正确答案8 | 否 | 同上 |
| 24 | 正确答案9 | 否 | 同上 |
| 25 | 正确答案10 | 否 | 同上 |
| 26 | 正确答案11 | 否 | 同上 |
| 27 | 正确答案12 | 否 | 同上（多项填空最多 12 个空） |
| 28 | 解析 | 否 | 支持富内容（见第三节） |
| 29 | 标签 | 否 | 多个用逗号或顿号分隔 |
| 30 | 图片 | 否 | 题目配图 URL（如 `/api/file?id=xxx`），多个用换行分隔 |

## 二、题型与答案填写规则

| 题型 | 选项列 | 正确答案列 | 示例 |
| --- | --- | --- | --- |
| 判断 | 留空 | 正确答案1 填 `正确` 或 `错误` | `正确` |
| 单选 | 选项A~D 等 | 正确答案1 填选项字母 | `B` |
| 多选 | 选项A~D 等 | 正确答案1~12 依次填字母 | `A`、`C`（分两列） |
| 单项填空 | 留空 | 正确答案1 填答案文本 | `3.14` |
| 多项填空 | 留空 | 正确答案1~12 按空位顺序各填一空 | `5x`、`3y`（分两列） |

> 若题目内图片/公式作为答案的一部分，答案列同样支持富内容语法。

## 三、富内容语法（题干 / 选项 / 解析通用）

学员端会自动渲染以下写法，**直接写在单元格文本里**：

| 内容 | 写法 | 示例 |
| --- | --- | --- |
| 图片 | `![图片说明](图片URL)` | `![数轴图](https://example.com/a.png)` |
| 行内公式 | `$...$` | `$x^2$`、`$\frac{a}{b}$`、`$|x|=3$` |
| 独立公式 | `$$...$$` | `$$\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$` |
| 化学式 | `$\ce{...}$` | `$\ce{2H2 + O2 -> 2H2O}$` |
| 加粗 | `**重点内容**` | `**注意单位**` |
| 换行 | 单元格内按 `Alt+Enter` | — |

约束：

- 图片 URL 必须是**公网可访问**的 `http`/`https` 地址，或系统内 `/api/file?id=xxx` 形式的文件地址。
- 公式内容为 LaTeX，**不要**在外面再套 `\( \)`；行内用单 `$`，独立用双 `$$`。
- 单元格内不要出现裸露的 `$` 金额写法与公式混用（如 `$5`），避免被误判为公式。

## 四、图片列用法

- 「图片」列（第 30 列）填写题目配图地址，写入题目的 `attribute.examImages`：题目列表显示「含配图」标记、编辑弹窗可查看/增删。
- 一个字格可放多个 URL，用换行分隔。
- 系统内图片地址形如 `/api/file?id=xxx`（`xxx` 为 `/api/file/create` 上传返回的 `id`），`GET /api/file?id=` 可直接访问。
- 也可不填本列，改为在题干里用 `![说明](图片URL)` 内联图片；两种方式学员端都会渲染。

## 五、校验规则（导入失败会整体中止并提示行号）

1. 学科必须已存在，章节必须属于该学科。
2. 小节若填写，必须属于该章节；知识点必须属于所填小节/章节。
3. 单选/多选必须提供选项（从选项A 起连续、不重复、至少 2 个），且正确答案字母能在选项中找到。
4. 多项填空的答案列数应与空位一致（按正确答案1~12从左到右顺序，最多 12 个空）。
5. 题型只允许上表 5 种。

## 七、给 AI 平台的指令模板（可整段复制）

```text
请把下面这批题目整理成一个 .xlsx 文件，用于导入「学海智习」题库。

要求：
1. 第一个 sheet 表头严格为以下 30 列，顺序与名称一字不差：
   学科,题型,章节,小节,知识点,题目,选项A,选项B,选项C,选项D,选项E,选项F,选项G,选项H,难易程度,正确答案1,正确答案2,正确答案3,正确答案4,正确答案5,正确答案6,正确答案7,正确答案8,正确答案9,正确答案10,正确答案11,正确答案12,解析,标签,图片
2. 题型只用：判断、单选、单项填空、多选、多项填空。
3. 答案规则：判断填「正确/错误」；单选填「A」；多选把字母依次填到“正确答案1..12”；单项填空填答案文本；多项填空把各空答案依次填到“正确答案1..12”（最多 12 空）。
4. 题干、选项、解析中如需图片，写 Markdown：![说明](公网http(s)图片URL)；
   也可把图片地址填到「图片」列（第 30 列），多个用换行分隔。
   如需公式，行内写 $...$，独立写 $$...$$，内容用 LaTeX；加粗写 **...**。
5. 学科/章节/小节/知识点必须使用系统中已有的名称，不要自造。
6. 每道题占一行，不要合并单元格，不要在单元格内写换行以外的排版。

待整理的题目如下：
（在此粘贴题目内容）
```

## 八、导入位置

「题目管理」页 → 「导入」→ 选择上面生成的 `.xlsx` → 确认导入。
