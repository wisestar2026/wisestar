# 英语题目难度分级标准

> 适用范围：英语题目模板、英语句子内容包、英语单元融合派生题。
> 唯一实现：`server/rdbms/src/main/java/cn/wisestar/server/core/uitls/EnglishDifficultyUtil.java`。
> 本文与代码同步维护；调整权重、阈值或正则时，必须同步修改本文与 `EnglishDifficultyUtilTest`。

## 1. 设计目标

三处英语题目入口共用一套可解释的规则评分模型，让同一道题在题目管理、内容包练习、单元组卷中得到一致的难度。模型只依据题干英文、答案、年级、题型、空位数与选项计算，不依赖人工标注，也不调用大模型。

评分结果内部为 5 个细分档位 D1~D5，对外输出 3 档：

| 细分档位 | 分数区间 | 三档 level | 标签 | 句子内容包 difficulty |
|---|---|---|---|---|
| D1 | 0~25 | 1 | easy | 1 |
| D2 | 26~41 | 2 | medium | 2 |
| D3 | 42~53 | 2 | medium | 2 |
| D4 | 54~73 | 3 | hard | 3 |
| D5 | 74~100 | 3 | hard | 3 |

调用方按需取用：题目模板取 `getLabel()`（easy/medium/hard），句子内容包取 `getLevel()`（1~3），融合题取 `getDLevel()`（D1~D3）。

## 2. 评分模型总览

```text
score = clamp(0, 100,
        作答方式基础分
      + min(24, 长度分)
      + 超长文本加分
      + min(18, 复杂度分)
      + 长词分
      + 作答负担分
      + 选项分)
```

各分项独立累加，除注明封顶外不互相抑制。最终分数向下映射到 D1~D5。

## 3. 作答方式基础分

作答方式由题型决定，基础分体现“认出答案”和“写出答案”的负担差异。

| Demand | 基础分 | 含义 | 典型题型 |
|---|---|---|---|
| RECOGNITION | 8 | 识别，只需选出正确项 | 单选、判断、情景选原句 |
| CUED | 26 | 有提示的产出，看中文/词库补全或挖空回填 | 单词填空、短语填空、选词填空 |
| APPLICATION | 28 | 应用，需要主动生成词形或句式 | 语法变形、换人称改写、语法选择 |
| FULL | 36 | 完整产出，需要独立组织整句 | 连词成句、默写、整句作答、Textarea |

三处入口的映射：

| 入口 | 题型 | Demand |
|---|---|---|
| 题目模板 | `FillBlank`、`MultipleBlank` | CUED |
| 题目模板 | `Textarea` | FULL |
| 题目模板 | 其他（`Radio` 等） | RECOGNITION |
| 句子内容包 | `choice` | RECOGNITION |
| 句子内容包 | `fill` | CUED |
| 句子内容包 | `build`、`dictation` 及其他 | FULL |
| 融合题 | 单词挖空、短语挖空 | CUED |
| 融合题 | 语法变形、换人称改写、语法选择 | APPLICATION |
| 融合题 | 情景选原句 | RECOGNITION |

## 4. 文本预处理

参与评分的文本由题干与补充文本拼接而成：

- 产出类（CUED/APPLICATION/FULL）：答案非空且与题干不同时，把答案追加到分析文本。
- 识别类（RECOGNITION）：正确选项文本非空且与题干不同时，追加正确选项文本。题目模板的答案字段是选项 ID，不参与分析；句子内容包的 `choice` 把答案文本同时作为正确选项文本传入。

预处理规则：

1. 删除所有全角括号及其内容，例如 `（它有多高？2020年时高8848.86米。）`。
2. 删除包含中文的半角括号及其内容，例如 `(它有多高)`。
3. 删除所有中文汉字、中文标点与全角字符。
4. 弯撇号 `’` 统一为直撇号 `'`。
5. 词元正则为 `[A-Za-z0-9]+(?:[.'’-][A-Za-z0-9]+)*`。数字、小数（`8848.86`）、缩写（`It's`、`don't`）和连字符词各按一个词计。
6. 句子数按字符 `.`、`?`、`!` 出现次数累加。

## 5. 长度分

年级决定起算长度：

| 年级 | shortMax |
|---|---|
| 一年级、二年级、三年级、四年级（含 `1年级`~`4年级`） | 6 |
| 五年级、六年级及其他/空年级 | 8 |

长度分公式：

```text
words <= shortMax        -> 0
words >  shortMax        -> min(24, 4 + (words - shortMax) * 3)
words >= 25              -> 额外 +4
words >= 30              -> 额外 +2
```

长度分最高 30 分。低年级用更短的起算长度，因此同一句在三年级会比五年级得分更高。

## 6. 复杂度分

复杂度分按特征是否出现计分，同一特征重复出现只计一次，总分封顶 18。特征正则按原句大小写匹配。

| 特征 | 分值 | 识别规则 |
|---|---|---|
| 从句/连接词 | +5 | `because`、`although`、`though`、`if`、`when`、`while`、`before`、`after`、`until`、`since`、`who`、`which`、`whose`、`where`、`unless`、`whether` |
| 转折/因果 | +3 | `but`、`however`、`so`、`therefore`、`instead`、`otherwise` |
| 基础情态 | +2 | `can`、`could` |
| 进阶情态/义务 | +4 | `will`、`would`、`shall`、`should`、`must`、`may`、`might`、`have to`、`has to`、`had to` |
| 被动语态 | +3 | `is/are/was/were/be/been/being` + 3 个字母以上且以 `ed` 或 `en` 结尾的词 |
| 比较级/最高级 | +3 | `more`、`most`，或 `3 个字母以上 + er/est + than` |
| 过去时等不规则动词 | +3 | `was`、`were`、`went`、`bought`、`saw`、`had`、`did`、`made`、`took`、`gave`、`came`、`ate`、`drank`、`wrote`、`rode`、`flew`、`swam`、`ran`、`sang`、`taught`、`thought`、`caught` |
| 多句 | +min(6, (句数-1)×3) | 句数大于 1 时叠加，最多 6 |
| 低年级结构加成 | +3 | 一~四年级出现从句、被动或比较级时叠加 |

长词分：长度不少于 10 个字母的词各 +1，最多 +2。例如 `beautiful`、`restaurant`、`grandmother`。

## 7. 作答负担分

仅 CUED 与 APPLICATION 计作答负担，RECOGNITION 与 FULL 不计。

| 项目 | 分值 |
|---|---|
| 答案词数 | `min(8, max(0, 答案词数 - 1) × 2)` |
| 空位数 | 空位数大于 1 时 `min(6, (空位数 - 1) × 2)` |

空位统计：在题干中每次找到连续 3 个下划线计 1 空，并把查找位置后移 3 个字符。题干应统一使用 `___`；6 个连续下划线会被计为 2 空。

各入口的空位数来源：

- 题目模板：优先取 `attribute.blankCount`，缺失时按题干统计。
- 句子内容包填空：按 `stem` 统计；其他题型按 0。
- 融合题：按英文原句统计。

## 8. 选项分

选项列表非空时：

| 条件 | 分值 |
|---|---|
| 选项数 >= 4 | +2 |
| 选项数 < 4 | +1 |
| 识别类存在近义干扰项 | 额外 +6 |

近义干扰项判定（排除与正确项相同的选项）：

1. 选项与正确项词数相同，且逐词比较仅有 1 个词不同（忽略大小写）。
2. 正确项不少于 3 词、选项不少于 2 词，首词相同，且词数相差 1。

## 9. 计算伪代码

```text
evaluate(title, answer, grade, demand, blankCount, options, correctOptionText):
    analysis = normalize(title)
    if demand != RECOGNITION and answer not blank and answer != title:
        analysis += " " + normalize(answer)
    if demand == RECOGNITION and correctOptionText not blank and != title:
        analysis += " " + normalize(correctOptionText)

    score = demand.baseScore
    words = countWords(analysis)
    shortMax = isLowerGrade(grade) ? 6 : 8

    score += min(24, words > shortMax ? 4 + (words - shortMax) * 3 : 0)
    score += words >= 25 ? 4 : 0
    score += words >= 30 ? 2 : 0

    complexity = 0
    complexity += hasSubordinate ? 5 : 0
    complexity += hasContrast ? 3 : 0
    complexity += hasBasicModal ? 2 : 0
    complexity += hasAdvancedModal ? 4 : 0
    complexity += hasPassive ? 3 : 0
    complexity += hasComparison ? 3 : 0
    complexity += hasTense ? 3 : 0
    complexity += sentences > 1 ? min(6, (sentences - 1) * 3) : 0
    complexity += isLowerGrade and (hasSubordinate or hasPassive or hasComparison) ? 3 : 0
    score += min(18, complexity)

    score += min(2, countLongWords(analysis))

    if demand in (CUED, APPLICATION):
        score += min(8, max(0, countWords(answer) - 1) * 2)
        score += blankCount > 1 ? min(6, (blankCount - 1) * 2) : 0

    if options not empty:
        score += options.size() >= 4 ? 2 : 1
        score += demand == RECOGNITION and hasNearMiss(options, correctOptionText) ? 6 : 0

    return clamp(score, 0, 100)
```

## 11. 落地与重算

| 入口 | 调用点 | 输出 | 重算方式 |
|---|---|---|---|
| 题目模板 | `TemplateServiceImpl.englishDifficulty` | easy/medium/hard | `POST /api/template/recalibrate-english-difficulty` |
| 句子内容包 | `EnglishSentencePackServiceImpl.difficultyOf(ex, grade)` | 1/2/3 | `POST /api/english/sentence-pack/recalibrate` |
| 融合派生题 | `EnglishFusionQuestionFactory.difficulty(...)` | D1/D2/D3 | 随组卷实时计算 |

两个重算接口都以当前规则全量重算并幂等写回：题目模板只更新难度发生变化的记录并返回改动题数；句子内容包逐包重写练习难度并返回处理的内容包数。调整规则后应依次执行模板重算、内容包重算，再导出 H2 快照。

历史重算结果（2026-10-21）：

- 英语题目模板 796 道：easy 402、medium 391、hard 3。
- 句子内容包 53 个、1881 道练习：难度 1 为 276、难度 2 为 1429、难度 3 为 176。

## 12. 已知边界与调参建议

1. 这是规则模型，衡量的是文本长度与可识别结构，语义抽象度、文化背景与推理层级不在模型内。
2. 复杂度特征按“是否出现”计一次，多个同类从句不会重复加分，长文本由长度分与多句分补偿。
3. 句子数按 `.`、`?`、`!` 字符累加，省略号与 `e.g.` 一类写法会被多计；题干应避免连续句点。
4. 被动、比较级与过去时依赖正则和有限词表，不规则动词表需按教材语料补充。
5. 空位按每 3 个下划线计 1 空，题干应统一使用 `___`。
6. 特征正则为大小写敏感，句首大写的连接词（如 `When`、`Because`）目前可能漏判；如需修正，应统一加 `Pattern.CASE_INSENSITIVE` 后重跑单测与全量重算。
7. 权重、阈值、正则均集中在 `EnglishDifficultyUtil` 常量区。调参顺序：先改常量与单测，再运行模板与内容包重算，最后核对三档分布并重导快照。
