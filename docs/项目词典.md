## 一、领域词汇表（先认字）

| 术语 | 含义 | 对应代码/表 |
|---|---|---|
| 题目 Template | 一道可作答的题（单选/多选/判断/填空…），题干与选项、标准答案存 JSON | `Template.java` → `t_template` |
| 题库 Repo | 题目的集合容器，题目通过 repoId 归属题库 | `Repo.java` → `t_repo`（**遗留表无 `is_deleted`**） |

| 练习 Practice | 学员进入题库/小节刷题的一次会话（专项/套卷/随机） | `PracticeRecord.java` → `t_practice_record` |

## 五、关键约定

- **响应格式**：`{code, data, message}`；分页 `PaginationResponse{total, list, current, pageSize}`，前端取 `res.data.list`。
- **全局异常与鉴权**：越权 403 / 未登录 401 以 **HTTP 200 + body.code** 返回；`GlobalExceptionHandler` 统一包装，未知异常只返回"服务出了点问题"。
- **认证**：RSA 加密密码登录 → Set-Cookie `sk-token`（JWT，7 天）→ `JwtTokenFilter` → `SessionCreationPolicy.STATELESS`。
- **权限**：`t_role.authority`（逗号分隔权限点）+ `builtin`；后端 `@PreAuthorize("hasAuthority('module:action')")`；前端 `MainLayout` 菜单 `required` 过滤 + `AuthGuard` 路由校验 + `usePermission().can()` 按钮级。权限点唯一权威清单在 `PermissionConsts`。
- **数据权限**：学员端内容接口按订单权限（`t_student_permission.expire_at > NOW()`）过滤；校区范围由 `CampusScopeService` 统一裁决（ALL/CAMPUS）。
- **判分一致性**：后端 `AnswerJudgeUtil` 与前端 `utils/practiceHelpers.js` 语义必须保持一致，改一侧需同步另一侧。
- **新增表/权限点**：同时修改 `init-h2.sql` + `init-mysql.sql`，并在 `PermissionConsts` 登记权限点。
- **文档维护**：本文档（总览/数据）与 `项目词典-后端-*.md`（类/方法）、`项目词典-前端.md`、`项目词典-接口.md`、`项目结构梳理.md` 需随代码同步更新；架构相关结论见 `架构稳定性评估与改造方案.md`。
