# 项目词典（wisestar AI 自习室系统）

> 本词典是项目的「字典式」索引：把代码、文档（`docs/开发维护日志.md`、`docs/AI自习室系统开发路线图.md`）、数据三者对起来。
> 用途：开发时快速定位「某个功能在哪、由哪些文件组成、数据存在哪张表、某个方法被谁调用」。
>
> **五大类目**：① 领域词汇表 → ② 功能词典 → ③ 文件词典 → ④ 方法词典 → ⑤ 数据词典

## 一、领域词汇表（先认字）

| 术语 | 含义 | 对应代码/表 |
|---|---|---|
| 题目 Template | 一道可作答的题（单选/多选/判断/填空…），含题干、选项、标准答案、分值 | `Template.java` → 表 `t_template` |
| 题库 Repo | 题目的集合容器（如「考试」「数学口算」），题目通过 repoId 归属题库 | `Repo.java` → 表 `t_repo` |
| 练习 Practice | 学员进入题库刷题的一次会话（专项/套卷/随机模式） | `PracticeRecord.java` → 表 `t_practice_record` |
| 错题 | is_correct=0 的逐题明细，错题本/错题库管理的数据来源 | `PracticeDetail.java` → 表 `t_practice_detail` |
| 判分 Judge | 将学生答案与标准答案比对得出对错 | `AnswerJudgeUtil.evaluate` / 前端 `practiceHelpers.js` |
| 交卷 Submit | 练习完成后把逐题作答提交后端复核判分落库 | `POST /api/practice/submit` |
| 学海积分 | 终身成长值：全学科学习行为累计，永久不清零、不兑换，仅用于头衔晋升与证书 | 学生端 mock：`useStudentStore.js` `PROFILE.points` |
| 学习币 | 学期消费币：分科产出，单科单学期上限 3000、学期清零、多科合并兑换商品 | 学生端 mock：`useStudentStore.js` `SUBJECTS[].coins` |
| 五级头衔 | 由学海积分自动晋升（初探者/勤学者/深耕者/善思者/领航者），永不降级 | 学生端 mock：`useStudentStore.js` `TITLES` |
| 荣誉证书 | 头衔达标自动颁发，解锁永久保留（档案页荣誉墙展示） | 学生端 mock：`ProfilePage.jsx` |
| 纯净学习模式 | 迎检模式：激励模块（积分/币/头衔/证书/商城/奖励提示）DOM 隐藏，仅留学习功能 | 学生端 mock：`useStudentStore.js` `pureMode` |
| 教材版本 | 学科下可切换的教材（人教版/苏教版/北师大版等），切换版本重置章节目录 | 学生端 mock：`useStudentStore.js` `versions` |
| 知识点（学生端） | 章节下的最小学习单元，带掌握度% + 评级（精通/熟练/夯实/待巩固/待攻克） | 学生端 mock：`useStudentStore.js` `chapters[].kps` |
| 试卷/问卷 Survey | surveyking 原生功能：可填写表单/问卷 | `Project.java` → 表 `t_project` |
| 答卷 Answer | 用户提交的一份问卷答案 | `Answer.java` → 表 `t_answer` |

## 二、功能词典（按功能查文件/数据/方法）

> 每个功能条目统一格式：**作用 → 前端文件 → 后端链路 → 数据表 → 方法调用链示例**。

### F1. 登录认证与账户体系
- **作用**：RSA 加密密码登录、注册、登录态恢复、登出；区分管理端与学员端。
- **前端**：`pages/login/LoginPage.jsx`（登录）、`pages/login/RegisterPage.jsx`（注册）、`stores/useUserStore.js`（全局登录态）、`components/common/AuthGuard.jsx`（路由守卫）、`api/user.js`。
- **后端链路**：`UserApi`（`POST /api/public/login`、`POST /api/public/register`、`GET /api/currentUser`）→ `UserServiceImpl` → `Account.java`（账号）/`User.java`（用户信息）。
- **数据**：`t_account`（登录凭据：auth_account/auth_secret/secret_salt）、`t_user`（用户信息：name/deptId…）、`t_user_role`、`t_role`。
- **方法调用链**：`LoginPage 提交` → `useUserStore.login()` → `api/user.js login()` → `POST /api/public/login`（前端用 `/api/system` 返回的 publicKey 做 RSA PKCS1v15 加密密码）→ `UserServiceImpl` 校验 → 响应 Set-Cookie `sk-token` → 存 Zustand → `AuthGuard` 校验 `isLoggedIn` 放行受保护路由。页面刷新时 `App.jsx` 挂载调用 `fetchCurrentUser()` 恢复登录态。

### F2. 学生端体系（海底AI自习室 · 学海智习系统 V2.0）
- **作用**：学生端全页面（纯前端 mock 原型，无后端）。双轨数值：学海积分（全学科永久累计，仅头衔/证书）+ 学习币（分科产出，单科单学期上限 3000、学期清零、多科合并兑换）。五级头衔（初探者/勤学者/深耕者/善思者/领航者）+ 证书荣誉墙；纯净学习模式隐藏全部激励模块。
- **前端**：`stores/useStudentStore.js`（zustand 全局状态 + 全量 mock：三科章节知识点/题目池/头衔/商品/今日数据）；公共布局 `pages/student/StudentLayout.jsx` + `student.css`；页面 `StudentHomePage.jsx`（首页三卡+今日总览）、`StudyPage.jsx`（研习三栏）、`KnowledgePage.jsx`（知识点四模式）、`ProfilePage.jsx`（荣誉墙）、`MallPage.jsx`（商城）；素材图在 `public/student-assets/`（logo-flower.webp、starfish.webp）。
- **后端链路**：无（原型阶段，mock 数据 + localStorage 记忆学科/版本/纯净模式）。
- **数据**：无（前端 mock；关键常量在 useStudentStore.js：SUBJECTS/TITLES/GOODS/TODAY/DAILY_TASKS/REWARDS/QUESTION_BANK）。
- **入口与跳转**：`App.jsx` 路由 `/student`（AuthGuard 包裹，StudentLayout 嵌套路由）→ index=首页、`study`=研习、`knowledge/:kpId`=知识点（`?tab=preview|practice|trial|wrong`）、`profile`=档案、`mall`=商城；管理端 `MainLayout.jsx` 菜单「学生端主页」进入，通栏「返回管理端」回 `/`。
- **交互**：学科胶囊 Tab 切换（版本下拉联动）、章节卡片展开知识点、知识点选中三栏联动、练习/试炼提交逐题判对错 + 顶部奖励提示 1.5s 自动消失、商城兑换多科合并扣款。

### F3. 在线练习闭环（核心）
- **作用**：学员选题库 → 三种模式刷题（专项/套卷/随机）→ 作答/即时判分 → 交卷 → 结果页 → 再来一组。
- **前端**：
  - 选题页 `pages/practice/PracticeHomePage.jsx`（列出「我的题库」→ 进入练习带 `repoId`）
  - 答题页 `pages/practice/PracticeSessionPage.jsx`（核心：加载题目 `loadQuestions`、作答 `handleAnswerChange`、即时判分 `handleConfirm`、交卷 `handleSubmit`、重启 `handleRestart`）
  - 组件 `components/practice/QuestionCard.jsx`（单题渲染+三态判分高亮）、`AnswerSheet.jsx`（答题卡）、`ExamIntro.jsx`（套卷说明）
  - 判分工具 `utils/practiceHelpers.js`（`evaluateAnswer`/`calculateScore`/`extractCorrectAnswers`/`optionIdsToTitles`）
  - API `api/practice.js`（`submitPractice`）
- **后端链路**：题库列表 `RepoApi.listRepo` → 题目列表 `TemplateApi.listTemplate` → 交卷 `PracticeApi`（`POST /api/practice/submit`）→ `PracticeServiceImpl.submitPractice`。
- **数据**：读 `t_repo`/`t_template`；写 `t_practice_record`/`t_practice_detail`。
- **方法调用链示例**：`PracticeSessionPage` 交卷 `useEffect`（submitRef 防 StrictMode 双调）→ `submitPractice({mode, repoId, durationMs, items})` → `PracticeApi.submitPractice` → `PracticeServiceImpl.submitPractice` → ① `templateService.list(...in Template::getId...)` 批量回源题目 → ② 逐题 `AnswerJudgeUtil.evaluate` 复核判分 → ③ `save(record)` + `practiceDetailMapper.insert(detail)` 落库。

### F4. 交卷落库与判分（1.9 核心）
- **作用**：后端**复核**判分（不信任前端结果，防篡改），写练习会话汇总 + 逐题明细（is_correct=0 即错题），为错题本/学习统计铺数据底座。
- **后端**：
  - `api/PracticeApi.java`：`POST /api/practice/submit`（`@PreAuthorize("isAuthenticated()")`）
  - `impl/PracticeServiceImpl.java`：`submitPractice`
  - `shared/.../uitls/AnswerJudgeUtil.java`（注意包名拼写 uitls）：`extractCorrectAnswers`/`evaluate`/`formatAnswer`
  - `domain/dto/PracticeSubmitRequest.java`：请求体 `{mode, repoId, durationMs, items:[{questionId, answer}]}`
  - 实体 `PracticeRecord`/`PracticeDetail` + Mapper
- **数据**：`t_practice_record`（会话：user_id/mode/repo_id/total_questions/correct_count/score/total_score/duration_ms）、`t_practice_detail`（明细：practice_id/question_id/question_type/user_answer/is_correct/score）。
- **判分约定**（与前端 `practiceHelpers.js` 对齐）：每题分值 = `attribute.examScore` 无则 1 分；答对得分、答错 0、无标准答案判 null 不计分不记错；`correct_count`=判对题数；单题异常跳过不阻断整单（数据底座健壮性）。
- **方法调用链**：`PracticeApi.submitPractice` → `PracticeServiceImpl.submitPractice` → `AnswerJudgeUtil.evaluate(schema, item.getAnswer())` → 汇总 → `save(PracticeRecord)` → `practiceDetailMapper.insert(PracticeDetail)`。建表 SQL 在 `scripts/init-h2.sql`/`init-mysql.sql`（`spring.sql.init.mode: always` 云端自动建表）。

### F5. 错题库管理（管理端）
- **作用**：把学员做错的题按「题目 × 学员」聚合展示（累计错误次数、最近答案/时间），支持按题库/题型/关键词（题目或学员名）/时间筛选。
- **前端**：`pages/practice/WrongQuestionPage.jsx`（筛选栏+聚合表格+分页）；API `api/practice.js` 的 `listWrongQuestions`。
- **后端链路**：`PracticeApi`（`GET /api/practice/wrong-list`）→ `PracticeServiceImpl.listWrongQuestions` → `PracticeDetailMapper.selectWrongQuestions`（窗口函数 SQL）。
- **数据**：读 `t_practice_detail`（is_correct=0）JOIN `t_practice_record`（取学员）JOIN `t_user`（姓名）JOIN `t_template`（题目信息）JOIN `t_repo`（题库名）。
- **方法调用链**：`WrongQuestionPage.fetchData` → `listWrongQuestions(params)` → `PracticeServiceImpl.listWrongQuestions` → `practiceDetailMapper.selectWrongQuestions(page, query)` → 聚合 SQL（`COUNT(*) OVER (PARTITION BY d.question_id, r.user_id)` 计次数 + `ROW_NUMBER() ... rn=1` 取最近一次）。
- **排障记忆**：`t_repo` 为遗留表**无 `is_deleted` 列**，SQL 里不能写 `rp.is_deleted=0`。

### F6. 题库管理（组题）
- **作用**：题库 CRUD + 从「题目管理」批量勾选题目组入题库（bind）；移除题目仅解绑（unbind）不删题（题目保留在题目管理）。
- **前端**：`pages/repo/RepoListPage.jsx`（列表 + 编辑弹窗=属性表单+组题区块）、`pages/repo/RepoDetailPage.jsx`（详情 + 批量选择/移除）、`components/repo/SelectTemplateModal.jsx`（批量选题目弹窗）、`api/repo.js`（`bindTemplate`/`unbindTemplate`/`listRepo`）。
- **后端链路**：`RepoApi`（`GET /api/repo/list`、`POST /api/repo/create|update|delete`、`POST /api/repo/bind`、`POST /api/repo/unbind`）→ `RepoServiceImpl`（`listRepo`/`bindTemplates`/`batchUnBindTemplate`）。
- **数据**：`t_repo`（题库：name/mode/shared/tag/is_practice）、`t_template.repoId`（题目归属，一题一库）、`t_repo_template`（组题关联表）。
- **调用链**：`SelectTemplateModal 勾选 → bindTemplate({repoId, ids}) → POST /api/repo/bind → RepoServiceImpl.bindTemplates → 更新 t_template.repoId`。

### F7. 题目管理
- **作用**：全局题目 CRUD、Excel 导入/导出、知识点四维筛选（学科/章节/难度/知识点）、答案/解析编辑。
- **前端**：`pages/question/QuestionListPage.jsx`、`components/question/QuestionEditModal.jsx`、`ImportModal.jsx`、`TemplatePickerModal.jsx`、`api/template.js`、`api/repo.js`（导入导出）。
- **后端链路**：`TemplateApi`（`GET /api/template/list`、`POST /api/template/create|update|delete`）→ `TemplateServiceImpl`；导入导出走 `RepoApi`（`POST /api/repo/import`、`GET /api/repo/export`）→ `RepoServiceImpl`。
- **数据**：`t_template`（含 `template` JSON 列存完整 schema：children 选项/attribute 答案分值）；标签表 `t_tag`。
- **题型枚举**：`SurveySchema.QuestionType`（Radio/Checkbox/Judge/FillBlank/Textarea…）。

### F8. 题库分配（教师给学员分配练习题库）
- **作用**：教师把题库分配给学员，学员端「我的题库」只出现分配给自己的题库。
- **前端**：`pages/repo/RepoAssignPage.jsx`；API 见 `api/repo.js`。
- **后端链路**：`RepoApi` 相关分配接口 → `RepoServiceImpl`（含 `userBookService` 查询用户练习记录回填姓名）。
- **数据**：`t_user_repo`（用户-题库分配关系）、实体 `UserRepo.java`。

### F9. AI 对话与思路讲解（1.8）
- **作用**：结果页/错题回顾点「AI 讲解」，按题流式输出思路讲解（当前按用户指示搁置了前端接入，后端能力就绪）。
- **后端**：`server/ai` 模块——`controller/ChatController`、`service/ChatService`/`AiChatService`、`service/impl/ChatServiceImpl`/`SiliconflowChatServiceImpl`（调 SiliconFlow 流式）、`domain`（ChatRequest/StreamResponseEvent/EventTypeEnum…）、`config/AiConfiguration`。
- **数据**：无落库（会话缓存 `ConversationCacheService`）。
- **说明**：系统配置需启用 SiliconFlow token 后才可用（见路线图 1.8）。

### F10. 问卷/答卷管理（surveyking 原生底座）
- **作用**：问卷项目 CRUD、问卷编辑器（schema 设计）、答卷收集/统计/导出。
- **前端**：`pages/project/`（list/edit/answers）、`pages/answer/`（AnswerListPage/AnswerDetailPage）、`pages/survey/SurveyViewPage.jsx`（公开填写页）、`api/project.js`/`api/survey.js`/`api/answer.js`。
- **后端链路**：`ProjectApi` → `ProjectServiceImpl`；`SurveyApi` → `SurveyServiceImpl`；`AnswerApi` → `AnswerServiceImpl`（含 `evaluateQuestionCorrect` 判分参考）。
- **数据**：`t_project`、`t_answer`、`t_answer_detail`。

### F11. 分析统计（Analysis）
- **作用**：知识点掌握度统计（配合练习/错题数据）。
- **后端**：`api/AnalysisApi.java` → `impl/AnalysisServiceImpl.java`；DTO `KnowledgePointQuery`/`KnowledgePointStat`。

## 七、端到端示例：一次「交卷产生错题 → 错题库可见」的完整链路

1. 学员在 `PracticeSessionPage` 答题，交卷（或倒计时自动交卷）→ `useEffect` 触发 `submitPractice({mode, repoId, durationMs, items})`
2. `POST /api/practice/submit` → `PracticeApi` → `PracticeServiceImpl.submitPractice`
3. 后端 `templateService.list` 按 questionId 回源题目 → 逐题 `AnswerJudgeUtil.evaluate` 复核判分 → 汇总写 `t_practice_record` 一条 + `t_practice_detail` 每题一条（`is_correct=0` 即错题）
4. 管理端打开「题库管理 → 错题库管理」→ `WrongQuestionPage.fetchData` → `GET /api/practice/wrong-list` → `PracticeServiceImpl.listWrongQuestions` → `PracticeDetailMapper.selectWrongQuestions`（聚合：同题同人错 N 次合并，取最近一次答案/时间）
5. 表格展示：题目/题型/题库/学员/错误次数/最近做错时间/最近答案/最近得分；可筛选题型、题库、关键词（题目或学员名）、时间范围
