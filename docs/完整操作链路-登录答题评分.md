# 第一步：登录

## 1.1 前端发来请求

浏览器（前端）向后端发了一个 HTTP 请求：

```
POST /api/public/login
Body: {
  "username": "admin",
  "password": "加密后的密码字符串"

前端在发请求之前，先调用了 `GET /api/system` 拿到了 RSA 公钥，用这个公钥把明文密码 `"123456"` 加密成了一长串乱码。所以传到后端的密码是加密的，即使被人截获也看不懂。

public UserInfo loadUserByUsername(String username) throws UsernameNotFoundException {
    LambdaQueryWrapper<Account> queryWrapper = Wrappers.<Account>lambdaQuery()
        .eq(Account::getAuthAccount, username);

    if (existAccount.getStatus() != VALID) {

## 4.5 自动评分 -- AnswerServiceImpl.java 第 614-637 行

private Answer beforeSaveAnswer(Answer answer) {
    ProjectView project = projectService.getProject(answer.getProjectId()); // 查出问卷
    computeExamScore(answer, project);     // 计算分数！
    return answer;

private void computeExamScore(Answer answer, ProjectView project) {
    if (project != null && ProjectModeEnum.exam.equals(project.getMode())
            && answer.getAnswer() != null) {
        // 创建评分器：传入问卷结构（含正确答案）和考生答案
        AnswerScoreEvaluator evaluator = new AnswerScoreEvaluator(
            project.getSurvey(),      // 问卷结构（里面有正确答案）
            answer.getAnswer()        // 考生提交的答案
        );
        // 计算总分
        answer.setExamScore(evaluator.eval());
        // 记录每题得分
        AnswerExamInfo examInfo = new AnswerExamInfo();
        examInfo.setQuestionScore(evaluator.getQuestionScore());
        answer.setExamInfo(examInfo);
    }
}
```

public class AnswerScoreEvaluator {
    private final SurveySchema schema;      // 问卷结构（有正确答案）
    private final LinkedHashMap answer;     // 考生答案

    public AnswerScoreEvaluator(SurveySchema schema, LinkedHashMap answer) {
        this.schema = schema;               // this.schema = 外面的那个 schema 参数
        this.answer = answer;
        // 注册四种计分规则
        evaluatorList.add(new OnlyOneEvaluator());      // 只有一个正确答案
        evaluatorList.add(new SelectAllEvaluator());     // 全部答对才得分
        evaluatorList.add(new SelectCorrectEvaluator()); // 按正确答案计分
        evaluatorList.add(new SelectEvaluator());        // 按选中的答案计分
    }

    public Double eval() {
        return doEval(schema);              // 从根节点开始递归计算
    }

    private Double doEval(SurveySchema qSchema) {
        double score = 0;
        // 找到匹配的计分规则，执行评分
        // ...
        // 递归：如果有子节点（题目套题目），继续算
        if (qSchema.getChildren() != null) {
            for (SurveySchema child : qSchema.getChildren()) {
                score += doEval(child);
            }
        }

| `private final SurveySchema schema` | 问卷结构，赋值后不能改 |
| `public AnswerScoreEvaluator(...)` | **构造器**：创建对象时自动执行，初始化字段 |
| `this.schema = schema` | `this` 指"我自己"，把参数值赋给我自己的字段 |
| `public Double eval()` | 公开方法，返回小数（Double） |
| `private Double doEval(...)` | 私有方法，内部递归用 |

**四种计分规则**（以我们的单选题为例）：

我们的题设为 `examAnswerMode: "onlyOne"`，所以匹配 `OnlyOneEvaluator`：

```java
class OnlyOneEvaluator implements Evaluator {
    public Double eval(SurveySchema qSchema) {
        Map qValue = (Map) answer.get(qId);       // 取出考生对这道题的答案
        for (SurveySchema option : qSchema.getChildren()) {     // 遍历每个选项
            if (option有正确答案 && qValue里包含这个选项 && 只选了一个) {
                return qScore;                    // 得分！
            }
        }
        return .0;                                // 没分
    }

    public boolean support(SurveySchema qSchema) {
        return examAnswerMode是onlyOne && 有分值 && 有答案;
    }
}
```

**翻译成人话**：
- 先判断这道题用什么计分规则（`support` 方法）
- 本题是 `onlyOne`，所以用 `OnlyOneEvaluator`
- 拿出考生的答案：`{"opt2": "2"}`
- 遍历每个选项，找到标了正确的那一项（opt2）
- 检查考生确实选了 opt2，并且只选了这一个
- 匹配！加 10 分

**如果考生选的是"1"**：遍历选项时发现 opt2 是正确答案但考生没选，opt1 被选了但不是正确答案 → 得 0 分。
